# BCE Website Setup

Four-page static website for BCE manufacturing. Serve the repository root with `python3 -m http.server 8000` and open `http://localhost:8000`.

- Home, Products, About, Contact
- Catalogue based on the product list in Globe International’s catalogue
- Original BCE branding and equipment illustration
- Enquiry form generates a plain-text brief locally

Before launch, confirm BCE's catalogue, contact details and delivery workflow. Once those details and the public URL are confirmed, configure lead delivery and production indexing.
